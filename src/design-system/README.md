# Design system (vendored)

Copied from the Puddle design system (`design-system/` in the project files; live at https://claude.ai/artifact/28ANZkPUmJP8q2oNBciPAS).

| File | Source |
|---|---|
| `tokens.css`, `tokens.json`, `tailwind.preset.js` | Generated by `scripts/tokens.py`. Edit `tokens.json` upstream and re-copy; don't hand-edit. |
| `components.css` | `components/bundle.css` without the Google Fonts `@import` (fonts are self-hosted in `fonts.css`). |
| `fonts.css` | Local: registers the self-hosted faces under the names the tokens use. |

The React components in `components/index.jsx` are ported to TypeScript in `src/ui/` with the same class names, and with `lucide-react` icons in place of the stand-ins (see the brand book's Iconography table).
